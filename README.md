# OPAMP設計 成果物

## 設計の説明
想定用途は照度センサーの出力増幅。速度動作は不要。
TR-1um(IP62プロセス)を用いた2段OPAMP。M1〜M12 + CSIO容量(位相補償)構成。

## AC解析結果
- 利得: 49.4 dB (1kHzでの利得)
- 単位利得周波数(ugf): 608 kHz
- 位相余裕: 59.2度
- 照度センサー(数百Hz以下)の用途には、6kHzの帯域は十分。
- 開ループ利得と閉ループ利得の差が小さく、精度(利得誤差)はやや大きめか。
- ※シミュレーションではCSIOモデルの互換性問題により理想容量で代用
- 詳細: `sable_AC解析結果.png` を参照

## 苦労したポイント
- DRC: PDK側のドキュメント探索に手間取り、CO.Z1(ポリコンタクト由来12件)の
  原因調査に時間を要した。最終的にレイアウトがIP62→TR-1um変換
  (IP62_to_TR-1um.py)を経ていなかったことが根本原因と判明し、変換を
  実施してDRCクリーンを達成。
- LVS: PDK提供のLVSスクリプトにconnect()定義(配線層間の接続)が
  存在しないことを発見。connect()を追加することで不一致を14件→3件まで
  削減。残り3件はCSIO由来のAN成分混入が原因と推定されるが未解決のまま
  提出。
